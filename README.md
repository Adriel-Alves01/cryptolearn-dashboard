## 📝 Sobre o Projeto

O **CryptoLearn** é uma plataforma educativa desenvolvida para análise e simulação de investimentos em criptomoedas. 

### 🌟 Principais Funcionalidades
- **Análise de Mercado:** Visualização de histórico de preços e indicadores.
- **Simulador de Carteira:** Realização de compras fictícias e gestão de portfólio.
- **Relatórios Automatizados:** Exportação de dados em CSV ou PDF.
- **Alertas:** Configuração de notificações para variações de preço.

## 🚀 Instalação e Execução

Copie e cole estes comandos no seu terminal:

```bash
# 1. Clonar o repositório
git clone [https://github.com/Adriel-Alves01/cryptolearn-dashboard.git](https://github.com/Adriel-Alves01/cryptolearn-dashboard.git)
cd cryptolearn-dashboard

# 2. Instalar dependências
pip install -r requirements.txt

# 3. Preparar o banco de dados
python coleta.py

# 4. Executar o Dashboard
streamlit run dashboard.py
```
